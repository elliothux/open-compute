这条路径安装当前正式版本，启动一个本机 instance，并部署最小 Worker。正式二进制支持 Apple silicon macOS、ARM64 Linux 和 x86-64 Linux。

## 让 AI coding agent 完成安装

把下面这段提示复制到 Codex、Claude Code 或其他 coding agent。代码块自带一键复制按钮：

```text
阅读 https://open-compute.dev/llms.txt，在这台机器上安装 open-compute 当前正式版本并配置一个本机 instance。先检查已有安装，默认保留现有配置和 instance 数据；使用 sudo 或执行破坏性操作前先询问我。最后运行 ocd status，并报告结果。
```

[`llms.txt`](https://open-compute.dev/llms.txt) 只包含最基本的 setup 和使用方式，需要时再按链接读取详细文档。

## 1. 安装

安装最新正式版本：

```sh
curl -fsSL https://open-compute.dev/install.sh | sh
```

Installer 会选择当前平台对应的二进制文件并验证 release checksum。它把 `ocd` 安装到 `~/.local`，把私有 receipt 存入 `~/.open-compute/install-receipt.json`，临时下载存入 `~/.open-compute/tmp/`。需要时它会更新支持的 shell 配置以加入 `~/.local/bin`，无法自动更新时会打印一条精确的 `export PATH=...` 命令。安装器不会创建配置、实例数据、密钥或 service。

## 2. 初始化平台

创建推荐的用户配置和数据目录，注册随登录会话运行的 user service，并启动第一个 instance：

```sh
ocd setup --yes
```

随后验证 instance 并打开 Dashboard：

```sh
ocd status
ocd dashboard
```

`status` 必须显示 ready。`dashboard` 打开一次性登录 URL，不要求复制长期 admin token。

这会创建一个作用域 daemon 及其第一个隔离实例。之后可用 `ocd instance setup --name staging --yes` 添加实例，再用 `--instance staging` 选择实例级命令的目标。详见[实例](/zh/docs/ocd/instances/)。

user service 会在下次登录时启动，但注销后可能停止。需要登录前启动的整机 service 时，显式安装并初始化 system scope：

```sh
curl -fsSL https://open-compute.dev/install.sh | sudo sh
sudo ocd setup --system --yes
```

## 3. 创建 Worker 项目

需要 Node.js 22.18 或更新版本。Bun 管理依赖，Node 执行 cf。

```sh
mkdir hello-worker && cd hello-worker
bun init -y
bun add -d cf@1.0.0-beta.21 @cloudflare/vite-plugin@2.0.0-beta.sha-52b0dc0e9 vite typescript
mkdir src
```

上述版本与内部 CI 基线一致。用户无需固定 cf：`1.0.x` 不警告，其他版本警告后仍允许执行。

创建 `cloudflare.config.ts`：

```ts
import { defineConfig } from "cf/config";

export default defineConfig({
  worker: {
    name: "hello-worker",
    entrypoint: "src/index.ts",
    compatibilityDate: "2026-09-08",
    workersDev: false,
  },
});
```

创建 `vite.config.ts`：

```ts
import { cloudflare } from "@cloudflare/vite-plugin";
import { defineConfig } from "vite";

export default defineConfig({ plugins: [cloudflare()] });
```

创建 `src/index.ts`：

```ts
export default {
  fetch(request: Request): Response {
    return Response.json({
      message: "hello from open-compute",
      path: new URL(request.url).pathname,
    });
  },
} satisfies ExportedHandler;
```

创建 `tsconfig.json`，严格检查官方生成的类型：

```json
{
  "compilerOptions": {
    "target": "ES2024",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "lib": ["ES2024"],
    "types": [],
    "strict": true,
    "noEmit": true
  },
  "include": ["src/**/*.ts", ".cloudflare/types/**/*.d.ts"]
}
```

## 4. 开发与部署

添加 package scripts：`dev: cf dev` 和 `build: cf workers types --mode production && tsc --noEmit && cf build --mode production`，然后运行：

```sh
bun run dev
bun run build
ocd cf deploy --prebuilt --mode production
```

`cf dev` 使用官方本地模拟资源，部署连接所选 open-compute 实例。日志使用 Dashboard Live Tail；cf 目前没有等价的终端流式命令。

旧 Wrangler 项目需显式执行 `cf migrate ./wrangler.jsonc --bundler vite`，完成 TODO 并配置 Vite。`ocd` 只诊断旧配置文件，不自动迁移。

下一步：[开发](/zh/docs/develop/)、[运维](/zh/docs/operate/)和[产品](/zh/docs/products/)。

npm 用户可用 `npm install` 和 `npm run dev/build`；pnpm 用户可用 `pnpm install --frozen-lockfile` 和 `pnpm run dev/build`。安装开发依赖分别用 `npm install --save-dev` / `pnpm add -D`。

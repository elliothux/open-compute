# 偏差

登记 ID：**`OC-R2-001`**。

R2 object bytes 由配置的 S3-compatible provider 持有。不声称 Cloudflare 全球 placement 或 replication。

110 个目标成员因此是 `supported_with_deviation`。没有第二个 R2 偏差 ID。没有 ID 不等于 Cloudflare 托管公开访问、jurisdiction 或全球复制可用。

见 [Compatibility](/platform/compatibility) 与 `docs/references/p1-deviations.md`。

# Document parser hostile corpus

These project-owned fixtures exercise bounded failure paths without depending on
network access or random generation. `seed.json` freezes all generator inputs and
the expected stable internal error for every case. `manifest.json` freezes the
generated byte size and SHA-256.

Regenerate deliberately with `python3 test/fuzz/corpus/document-parser/generate.py --write`.
Ordinary validation must use `--check`, which generates into an operating-system
temporary directory and compares exact bytes without modifying the repository.

The fixtures are synthetic inputs created for open-compute and are covered by the
repository license. They contain no third-party document content.

## 实现与不变量

- 每个 D1 database 拥有独立 SQLite 文件；control catalog 管理身份、binding、生命周期和迁移记录。
- 同步 prepare／bind 链在 tenant isolate 中构造；执行通过私有二进制协议进入受控 database operation lane。
- SQLite authorizer、limits 和 progress handler 限制 SQL 与执行资源，连接和任务由有界 handle manager 管理。
- `batch` 使用单事务，任一语句失败则整批回滚；`exec` 按其顺序执行合同处理已提交前缀。
- Commit 后 response loss 是结果未知，不能伪装成已回滚或自动重放写入。
- Tenant migrations 是产品数据操作，与平台 Day1 schema 管理分开。
- 在线 backup 校验一致性；restore 创建新资源。单 database 损坏不影响其他 database 的服务。
- 当前 session、bookmark、返回 metadata 与管理面支持以兼容矩阵为准，不沿用阶段初期子集。

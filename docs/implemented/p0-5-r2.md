# P0.5：R2

> 状态：Implemented and verified（2026-08-25）

已完成阶段的维护摘要；当前支持范围见[兼容矩阵](../references/cloudflare-compatibility.md)。

## 实现与不变量

- 逻辑 bucket 的账号、资源生命周期与访问能力由控制库管理；对象操作经过 R2 domain store。
- 对象后端已统一为 Local／S3，实际格式与 authority 见 [P8](p8-local-s3-object-backend.md)。
- 同步 object 方法与 body 消费状态在 tenant isolate 中实现，终端存储操作才进入私有 transport。
- Key、options、metadata、checksum、条件请求及 range 在对应 authority 边界验证；错误与响应保持公开合同。
- 上传与下载保持有界 streaming；multipart staging、分片、complete 和 abort 在重启后可恢复，complete 前对象不可见。
- 区分确定失败与 commit 后响应丢失的未知结果；不能无条件重试 mutation。
- 资源 pin、并发预算与取消共同控制存活期；删除与维护操作只处理所属资源。

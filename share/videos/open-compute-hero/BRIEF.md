## Intent

Create a silent, motion-first website hero film for open-compute. It should make
abstract infrastructure behavior immediately legible: requests and bindings
converge, one Rust-powered binary takes control, and the resulting runtime stays
on the operator's own infrastructure. The treatment should feel technically
precise, cinematic, fast, and unusually polished.

## Assets

- `https://www.unkey.com/videos/home/hero-av1.mp4` — primary reference for abstract feature visualization, network lines, restrained type, negative space, grain, and brief glitch transitions.
- `references/hyperframes-launches/k3-promo/` — implementation reference for deterministic geometry, dense motion staging, rapid semantic transformations, and finishing effects.

## Customizations

- Preserve a low-contrast safe region across the bottom 28% so the future website hero headline, body copy, and CTA can sit at the lower edge like Unkey's layout.
- Use diagrammatic connections, signal routing, scanlines, noise, chromatic fault frames, and one strong stack-collapse transition.
- Visualize supported concepts only: Workers-compatible code and bindings, one Rust-powered binary, SQLite authority, supervised workerd isolates, immutable deployments, and operator-owned infrastructure.

## Notes

- No logos or wordmarks anywhere in the video.
- Reusing generic icons or product names is allowed; favor concise monospaced labels over brand marks.
- English on-screen text to match the website.
- Silent loop-friendly composition; the first and last frames should remain dark enough to cut or crossfade cleanly.
